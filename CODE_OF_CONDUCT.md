# Code of conduct

## The short version

Be decent. Assume the other person is acting in good faith, and give them the
same benefit of the doubt you would want.

## What is expected

- Keep criticism about the work rather than the person.
- Accept that a disagreement can end with the other person still disagreeing.
- Take correction plainly. This project publishes its own mistakes on purpose,
  and it would be strange to hold contributors to a different standard.

## What is not acceptable

Harassment, personal attacks, discrimination, publishing private information,
and sustained disruption of discussion.

## Reporting

Mail rajeevchaurasia.dev@gmail.com. Reports stay private. If a report concerns
the maintainer, say so and it will not be handled by him alone.

## Scope

This applies in the issue tracker, pull requests, and anywhere someone is
representing the project.
